# 第3课分层样板

用来对比新旧两版的阅读效果：

- 旧版：[notes/lecture-03/课堂笔记.html](../../notes/lecture-03/课堂笔记.html)（2026-10-22 交付）
- 新版：[课堂笔记-分层样板.html](课堂笔记-分层样板.html)

| 文件 | 来源 |
|---|---|
| `notes.json` | 由 `build.py` 从旧版 HTML 迁移生成，加上 `layer.json` 的内容（notes v3） |
| `layer.json` | 本次新增：课程地图、17 张图解及各自依据的条目；44 段正文里要挪到“核对与边界”的原句；5 处有记录的改字 |
| `visuals/*.svg` | 整理者图解，400 宽画布、文字 ≥16，手机上约 13px 以上 |
| `build.py` | 重建页面并做迁移校验：旧版 198 个文本块逐句（按 。；？ 切分）都必须出现在新页面的正文或“核对与边界”中，18 幅原帧逐字节一致，否则构建失败 |
| `review/` | 独立评测：`fidelity-eval.json`（精度 + 迁移召回）、出题与作答原件 |

```sh
python3 examples/lecture-03-layered/build.py
python3 skills/baocut-course-notes/scripts/fidelity_eval.py --notes examples/lecture-03-layered/notes.json --eval examples/lecture-03-layered/review/fidelity-eval.json
```

## 免责句怎么处理的

正文里关于证据边界的说明（“录像没有给出……”“不能据此……”“原 ASR 写……”）**整句原样**移到该段下方的“核对与边界”小字，没有删除。只有 5 处改了字，均记录在 `layer.json`：

- s4:p0：“它衡量”补成“z-score衡量”，因为前一句已经移走。
- s5:p2：删掉元说明“由此保留课堂真实的条件句：”。
- s9:p1：逗号改句号，以便把后半句移出去。
- s2:p4：“如今大盘中枢向下”改成“授课时大盘中枢向下”，防止正文单独读起来像当前的市场判断。
- s8:p1：“他观察到”改成“他自述观察到”。

后两处是评审指出的：限定挪走之后，正文单独读会比原意更强。讲师自己的不确定语气（“他认为”“个人经验”）都留在正文里。

## 评测结果（2026-10-27）

- **精度 82/82 supported**。评审是一个没参与写作的子代理，对照旧版笔记全文检查：课程地图、17 张图解、20 句一句话结论、44 段改写正文。
  - 首轮有 9 项为 partial：7 张图丢了归属或条件，2 段正文的限定被挪走后读起来更强。全部修改后复核通过。
  - 复核时又发现 2 张图的新措辞过度：一张把“不认为有必要立刻做空”画成“没做空”，另一张漏了“看错方向”这一风险。也已修正，再次复核通过。
- **迁移召回 0.98**（25 题，24 correct、1 partial）。题目由同一评审从旧版出，另一个只能看到新页面文字的子代理作答。
  - 唯一的 partial 是 q18：答案要点“公司并未发生相应坏事”在 s14:p1 正文里，是答题者漏写，不是笔记缺失。

## 边界

- 召回题出自旧版笔记，不是原始转写。它证明分层改写没有丢信息，不证明对课程本身的召回；本地没有本课转写，所以也无法重新做 `source_ids` 覆盖校验。
- 第 9、17、20 节没有画图解：这几节没有比文字更适合用图表达的结构。
- 外部资料、整理者说明和自测题沿用旧版原文，没有改写。
